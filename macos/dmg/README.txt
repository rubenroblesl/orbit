Orbit for Mac

Installation
1. Drag Orbit to the Applications folder.
2. Open Orbit from Applications.
3. If macOS says it cannot verify the developer, open System Settings, go to Privacy & Security
   and select "Open Anyway" next to the Orbit message. You only do this the first time. Orbit is
   not signed with an Apple developer certificate.
4. Follow the setup assistant. You need your own copy of Super Mario Galaxy (USA, RMGE01) and
   Apple's command line tools, which the assistant installs.

Requirements
- A Mac with Apple Silicon and macOS 14 or later.
- 12 GB free during installation and 3.5 GB afterwards.

Orbit includes no game files. It is not affiliated with or endorsed by Nintendo.
